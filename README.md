# 🚀 Raman Khan Ahmadi | Angular Developer Portfolio

Welcome to the source code of my personal portfolio website! This project showcases my skills as an **Angular Developer & Frontend Engineer**, featuring my latest projects, career experience, and technical expertise.

🔗 **Live Demo:** [https://leonkhan10.github.io/portfolio/](https://leonkhan10.github.io/portfolio/)

## ✨ Key Features

- **Modern Angular Architecture:** Built with **Angular 21**[cite: 6], utilizing Standalone Components, strict typings, and `OnPush` change detection strategy.
- **Reactive State Management:** Fully powered by Angular **Signals** and **RxJS** for predictable, high-performance state handling.
- **Dark Mode Support:** Seamless Light/Dark theme switching with smooth transitions using Tailwind CSS v4[cite: 6].
- **Multi-language (i18n):** Integrated English (`en`) and German (`de`) localizations.
- **Server-Side Rendering (SSR):** Optimized for SEO and fast initial load times[cite: 1, 6].
- **Smooth Animations:** Scroll reveal effects and stagger animations powered by the `motion` library[cite: 1, 6].
- **Responsive Design:** Mobile-first approach ensuring a flawless UI across all devices.

## 🛠️ Tech Stack

## 💻 Local Development

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/leonkhan10/portfolio.git](https://github.com/leonkhan10/portfolio.git)
   cd portfolio


## Install dependencies:
Make sure you have Node.js installed, then run:

## Bash
npm install

## Start the development server:
## Bash
npm start

Navigate to http://localhost:4200 in your browser. The application will automatically reload if you change any of the source files.

## Build for production:

## Bash
npm run build
